# BOQ Pricing Workbook | جدول الكميات والتسعير

Excel workbook for general-contractor BOQs: finishes, civil, joinery, waterproofing (MEP excluded).

## Structure
Cover · Rates (M + L + E) · BOQ · Factors · Summary · Dimensions Reference

Cost build-up: Material + Labour + Equipment = direct cost, then indirect %, contingency %, profit %, sell price.
All results are live formulas. Blue = input, black = formula, green = cross-sheet link.

## Free sample
`SampleProject_BOQ_20261002_v1.xlsx` is a sample BOQ on an invented project, with invented rates. No client data.
